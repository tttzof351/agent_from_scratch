# LLM-агент с нуля

Учебный проект на Python: от простого запроса к LLM до интерактивного агента, который читает и редактирует файлы и выполняет Bash-команды. Запросы отправляются в OpenRouter напрямую через `urllib`, без SDK и агентных фреймворков.

Каждый шаг — отдельный скрипт, демонстрирующий следующий этап реализации.

## Запуск

Понадобятся Python 3.12 или новее и `uv`. Выполняйте команды из корня репозитория.

Установите зависимости:

```bash
uv sync
```

Создайте файл `.env` в корне проекта и укажите свой API-ключ OpenRouter и модель:

```dotenv
OPENROUTER_API_KEY=ваш_ключ
MODEL_NAME=openrouter/free
```

Запустите нужный шаг одной из команд:

```bash
uv run python step1/main.py
uv run python step2/main.py
uv run python step3/main.py
uv run python step4/main.py
uv run python step5/main.py
```

В шагах 4–5 вводите сообщения после приглашения `>>>`. Для выхода нажмите `Ctrl+C`.

Запросы и ответы сохраняются в `logs/` в текущем рабочем каталоге. При каждом запуске содержимое этой папки удаляется. Относительные пути файлов и Bash-команды в шаге 5 также используют текущий рабочий каталог.

## Шаги

| Шаг | Тема | Что реализовано |
| --- | --- | --- |
| [step1](step1/main.py) | Первый запрос к LLM | Отправка системного и пользовательского сообщений, вывод JSON-ответа модели. |
| [step2](step2/main.py) | Объявление инструмента | Добавление схемы инструмента погоды в запрос. Модель может запросить его вызов, но скрипт пока только выводит ответ. |
| [step3](step3/main.py) | Выполнение инструмента | Обработка вызова инструмента погоды, генерация случайного прогноза и передача результата модели в повторном запросе. |
| [step4](step4/main.py) | Интерактивный агент | Диалог с сохранением истории в памяти. Цикл выполняет вызовы инструмента погоды, пока модель не вернёт текстовый ответ. |
| [step5](step5/main.py) | Работа с файлами и Bash | Интерактивный агент с инструментами чтения диапазона строк, создания файлов, замены уникального фрагмента текста и выполнения Bash-команд. |
